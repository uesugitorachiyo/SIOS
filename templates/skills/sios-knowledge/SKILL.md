# SIOS knowledge

Use the SIOS client designated by the operator. Establish the intended instance, available methods, actual scopes, and which store is authoritative. Health alone does not establish identity, permissions, source coverage, or authority. Read applicable registered guidance before private retrieval or capture. If authority or the required client is unavailable, report the gap; do not choose another writer.

For current work read the full authoritative Mission and its revision. For historical context search the operator's configured Memory route; use results to locate full authorized sources and compare the full revision. Read declared predecessor and available successor evidence. Identify stale, missing, partial, or unverified sources; a search miss does not establish absence. Treat project tags as search filters, not access controls. Resolve corrections before presenting a claim and cite the source path and full revision when available.

Select a reusable Memory delta only when the owner authorized capture and the configured client has the necessary scope. Include personal information only when necessary and authorized; redact or aggregate where practical. Exclude secrets, unrelated personal information, transcripts, and material marked not to save. Preserve source, actor, date, scope, uncertainty, and any correction relationship. Deduplicate against relevant full sources; write once with a stable request ID using the client's supported contract. On an uncertain write, follow its documented reconciliation procedure without creating a new identity or replaying an unsafe request. Verify the full stored record and search visibility separately. No capture implies Brain promotion, Mission changes, scheduling, or external action.
