# Weekly review

Establish the operator's timezone, review period, current guidance, authorized Mission inventory, and report authority. Read full current Mission revisions and relevant logs; distinguish active, completed, and unknown states. Read only authorized current goals and relevant evidence. If inventory or full records are missing, mark the affected coverage incomplete.

Summarize observed progress, customer or outcome evidence where relevant, overdue next actions, unresolved decisions, and gaps. Include personal information only when necessary and authorized; redact or aggregate where practical. Separate observations from inference. Check routine history against an actually authorized schedule; an unavailable schedule or history makes missed-run status unknown. Identify stale knowledge for owner review without editing or promoting it. Give a small number of executable next actions with owners and dates when supported.

Use the configured report route only with actual authorization and scope. Keep stable occurrence and request IDs, reconcile uncertain writes, and verify the report and run metadata by readback. Otherwise return a draft with its limitations. Do not silently edit Missions, promote Brain, schedule work, or send external messages.
