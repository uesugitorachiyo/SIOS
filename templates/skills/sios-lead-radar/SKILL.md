# Lead radar

Establish the operator's current offer, geography, source types, timezone, report authority, and actual scopes from authorized current guidance. When any is unknown, label it instead of assuming a previous operator's business. Check prior authorized report history; if unavailable, mark deduplication partial.

Screen a bounded set of public sources, preferring original records. Verify the changed fact and date against its primary source when possible; distinguish publication and access dates. Record checked sources, unchanged or irrelevant items, and failures. A public signal suggests possible need; it does not establish demand or willingness to pay. Do not contact prospects, submit forms, create accounts, or collect private personal contact information as part of research.

Report up to the verified signals with direct citations, practical relevance, limits, and one optional internal discovery recommendation. This recommendation does not authorize outreach or form submission. Zero signals is valid when the checked coverage supports it. Mark partial coverage when important sources fail. Publish only through the designated authorized report route, using stable run and request IDs, reconciliation after uncertainty, and report and run-metadata readback. Otherwise preserve a draft.
