# Morning brief

Read applicable SIOS guidance and establish the report authority, client scopes, operator timezone, focus, and designated Mission inventory. Read current full Mission revisions and extract up to three actionable next moves. If required sources are unavailable, mark the moves incomplete instead of filling gaps with historical records.

If discovery is requested, check public primary sources and verify each item, event date, link, and practical relevance. Distinguish publication, event, and access dates; label author claims and unknowns. Compare prior authorized report history for duplicates and say when history is incomplete. Do not execute discovered code, contact anyone, or change schedules.

Write a concise report with dates, sources, limitations, and status reflecting actual coverage. Where report publication is authorized and available, use one occurrence ID and one request ID per intended run; preserve them after an uncertain response. Follow the client's reconciliation rules, then read the report and run metadata back. If publication is unavailable, keep a draft and report the gap.
